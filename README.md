# CSET 105 Lecture 4: Arrays

## Lecture Info
This lecture introduces JavaScript arrays, & how they can be used to support multiple values within a single variable.

## Features
- Basic grocery list using push & unshift array functions
- Table of multiple students' information contained within a single array
- Grabbing specific array elements using index numbers

## Practice
1. Prompt for a number of numbers to add, then find the sum of those numbers
2. Calculate & find the Nth term of the Fibonacci sequence
3. Create a function that removes an array element at a specific index
4. Create a function that adds an array element at a specific index
5. Write a basic grocery list manager that gets the number of groceries & their names, with an option to then search the list for a particular item. The program does not quit until the user says so.
6. Write a more advanced grocery list manager that has options to add groceries, search them, remove them, & print the entire list. The program does not quit until the user enters the option to do so.

## Exercises
1. Create a function that gets the maximum of a user-specified list of numbers, without using Math.max
2. Create a function that reverses the order of digits in a number, while keeping the negative sign if applicable
3. Create a function that converts all characters in a string to uppercase, without using toUpperCase
4. Create a function that inverts the cases of all characters in a string
